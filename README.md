# yandex-diploma-GophKeeper

Client-Server system, that safely stores your private data (login - passwords, bank cards, file data)

### Client

##### Build Client

* For Windows:
  
  ````sh
  make build_win_client
  ````
* For Mac:
  
  ```sh
  build_mac_client
  ```
* For Linux:
  ```sh
  make build_linux_client
  ```
